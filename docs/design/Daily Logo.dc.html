Rules
  • The arc is the only mark. Never pair it with an icon tile.
  • Arc and "ai" always share one colour — orange on light, #c0512b; lighter orange on dark, #e2794d.
  • Below 14px the arc thickens to stroke-width 2.6 so it survives.
  • Leave at least 0.5em clear above the arc — it overshoots the cap height.
  • Name is "Daily". "Brief" has been retired.
