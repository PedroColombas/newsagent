The pipeline
1. Turn topics into search queries — Anthropic (Haiku 4.5, cheap)
Genres and subtopics are already clean strings, so they need no help. But a custom interest is free text — "what China is doing in chip development" — so a small, fast Claude call converts each one into a tidy search label. Runs once per custom interest, costs fractions of a cent. This is the call that failed when your balance ran out, which is why brief 1 died first.

2. Find out what happened — Perplexity (sonar-pro)
One search per topic. Perplexity both searches the web and writes a sourced summary of what it found, which is precisely why it was chosen over a raw news API — otherwise you'd be building your own scraping, ranking and deduplication layer. It bills two ways: per token like any LLM, plus a per-request search fee for the actual web search.

3. Write the brief — Anthropic (Opus 4.8)
Takes all the per-topic research plus your preferences — length, tone, exclusions, catch-up depth — and writes the sectioned report. This is the heaviest step by far: every topic's research goes in as input, and the whole report comes out.

3b. "While you were away" — Anthropic (Sonnet 4.6), only when there's a gap
Condenses the briefs you missed. It's summarising text you already have rather than researching, so it runs on a cheaper model and triggers no new searches.

4. Write the podcast script — Anthropic (Sonnet 4.6), only when requested
Rewrites the finished report into a two-person interview, tagging each turn with the section it covers (that's where chapters come from).

5. Speak it — OpenAI (gpt-4o-mini-tts)
Each turn is voiced by its speaker, chunks are synthesised in parallel, then stitched together with ffmpeg along with the intro sting. This is the only place OpenAI is used, and it only runs for podcasts.
