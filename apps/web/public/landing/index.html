Daily Brief

A personalised news briefing, written fresh each weekday from the topics you choose — and narrated as a two-voice podcast.

Try the demo View the code

The demo signs you in automatically. No email, no sign-up.

The problem

Following a few specific subjects properly means checking several sources every day, or subscribing to newsletters written for someone else's interests. Neither gets you a single thing to read over coffee.

Daily Brief takes the topics you actually care about — including ones you describe in your own words, like “what China is doing in chip development” — researches each one separately every weekday, and writes one brief in one voice. If you'd rather listen, it records itself.

What it looks like

Real output from the running app, not mock-ups.

How it works

One brief is a four-stage pipeline. Each topic is researched on its own rather than lumped into a single query — that one decision is what separates writing that is specific from writing that is vague.

The stack, and why

Perplexity sonar-pro

Search and synthesis in one call, with citations — so there is no scraping, ranking or deduplication layer to build and maintain.

Anthropic Claude

Three jobs, three model sizes: Haiku turns free text into search queries, Opus writes the brief, Sonnet scripts the podcast.

Trigger.dev

Durable orchestration. Each stage is idempotent and retried on its own, so one failed step never sinks the whole run.

Supabase

Postgres, auth and a private audio bucket, with row-level security on every table. The pipeline writes with a service role; the app reads as the user.

React on Vercel

A mobile-first installable PWA. Designed for a phone first because that is where a morning brief is actually read.

OpenAI TTS + ffmpeg

Each speaker voiced separately and synthesised in parallel, then assembled into one episode with a branded intro.

What isn't built yet

  • Reader-chosen sources per topic — interesting design work, deliberately deferred.
  • Subscription billing. The unit economics are modelled; the checkout is not built.
  • Push notifications when a brief lands.
  • A native iOS wrapper. The PWA installs to the home screen today.
